# MacPeek 0.4.1

Reach a port on your Mac from anywhere: MacPeek can now let your MacPeek Remote devices open an end-to-end encrypted tunnel to a port on this Mac, such as its SSH server or a dev server. It is off until you turn it on. Still free, open source (MIT), no telemetry, and MacPeek needs no account. Apple silicon and Intel, macOS 13 or later.

## Highlights
- **Allow tunnels**: a new switch in Remote management lets your account's devices reach a port on this Mac's own `127.0.0.1`, on the local network or through the relay.
- **SSH from MacPeek Remote**: MacPeek now tells your own consoles the user name it runs as, so MacPeek Remote can open `ssh you@…` to this Mac in one click.

## Tunnels (off by default)
- **Settings > Remote management > Allow tunnels** has four choices: **Off**, **SSH only**, **SSH and chosen ports**, **Any port**.
- Only devices of this Mac's MacPeek Remote account with **View and act** can open a tunnel. Lowering access to **View only**, or narrowing the switch, closes the tunnels already open.
- A tunnel connects only to `127.0.0.1` on this Mac and carries one TCP connection, sealed frame by frame. On the local network it goes directly; from anywhere it goes through MacPeek's relay (needs MacPeek Remote Pro), and the relay sees only encrypted bytes.
- Open tunnels are listed in Settings and in the menu-bar icon's right-click menu, each with **Close**. Each tunnel is recorded in the activity log with its bytes and how long it was open.

## Changelog (v0.4.0 -> v0.4.1)

### Added
- Remote management: **Allow tunnels** (Off, SSH only, SSH and chosen ports, any port), with open tunnels listed in Settings and the menu-bar menu, **Close** on each, and an activity log entry per tunnel
- Remote management: `device.info` reports the short user name MacPeek runs as, only to the consoles of the Mac's account, for SSH. Older consoles ignore it

### Changed
- Tunnels close when the account's access drops to View only. After connecting to the port, the Mac checks Allow tunnels and the device's role again

### Fixed
- A console reached through the relay was told the Mac allows no tunnels. What Allow tunnels allows is now reported on every route

## Upgrading
- MacPeek offers the update itself (Settings > Updates > Check for Updates…), or download **MacPeek.dmg** below.
- No new permissions or entitlements.
- Tunnels stay off unless you turn them on. Tunnels and SSH from anywhere need **MacPeek Remote 0.2.0** or later.
