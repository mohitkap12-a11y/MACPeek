# MacPeek 0.4.0

Get MacPeek updates early: a Mac can now opt in to preview builds and receive them before everyone else. Nothing changes for anyone who doesn't opt in. Still free, open source (MIT), no telemetry, and MacPeek needs no account. Apple silicon and Intel, macOS 13 or later.

## Highlights
- **Preview builds**: an opted-in Mac is offered `-beta` releases through a separate update feed, ahead of the stable release.

## Preview builds (opt-in)
- Turn it on in Terminal, then quit and reopen MacPeek:
  ```bash
  defaults write app.macpeek.MacPeek receivePreviewBuilds -bool YES
  ```
- While it is on, Settings > Updates shows **Preview builds**. **Back to stable** turns it off, as does `defaults delete app.macpeek.MacPeek receivePreviewBuilds`.
- A preview stays installed after you leave until the next stable release replaces it: MacPeek never installs an older version.
- Previews are signed, notarized and verified exactly like stable releases. The only difference is which update feed the app reads, and that feed is on GitHub like the stable one.

## Changelog (v0.3.3 -> v0.4.0)

### Added
- Preview builds: opt-in update feed (`appcast-beta.xml`) for `vX.Y.Z-beta.N` releases, with **Preview builds** and **Back to stable** in Settings > Updates

### Changed
- The build number (`CFBundleVersion`) has no hyphen (`0.4.0-beta.1` becomes `0.4.0b1`), so updates put previews before their release
- Release workflow: `vX.Y.Z` is stable, `vX.Y.Z-beta.N` is a preview, any other hyphenated tag is a dry run; every stable and preview release updates the preview feed

## Upgrading
- MacPeek offers the update itself (Settings > Updates > Check for Updates…), or download **MacPeek.dmg** below.
- No new permissions or entitlements.
- Preview builds stay off unless you turn them on.
