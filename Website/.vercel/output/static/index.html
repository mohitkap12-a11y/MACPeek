The tiny utilities
macOS should have built in.

One small menu-bar app with a growing set of focused utilities for finding, inspecting and understanding the things macOS makes hard to see. PortPeek, DisplayPeek, USBPeek, NetPeek, SleepPeek, FileLockPeek, ProcessPeek, DiskPeek, EnvPeek and DNSPeek are ready; the first release is on the way.

How it works

Install once. Peek at anything.

Install MacPeek

Drag it to Applications. It lives in the menu bar: no Dock icon, no window.

Choose your utilities

Open Manage utilities to read what each Peek does, what it reads and what access it needs, then switch it on or off.

Peek

Click the icon, pick a utility or search for it, and get your answer in seconds.

Built in the open

Private by design.

MacPeek reads information from your Mac to show it to you, and never sends it anywhere. See exactly what each utility reads.
