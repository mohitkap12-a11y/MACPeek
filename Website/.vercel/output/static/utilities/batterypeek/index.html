BatteryPeek: Understand your MacBook battery.

What is my MacBook battery actually doing?

Coming soon. BatteryPeek is in development and is not part of the current MacPeek release. This page describes what it is planned to do; the screen below is an illustration, not the finished app.

The problem

How healthy is your battery, how many cycles has it done, and why is it not charging? macOS spreads the answers over Settings, System Information and Terminal.

The solution

BatteryPeek will show charge, power source, charging state, cycle count and the health and capacity indicators macOS reports. Estimates are labelled as estimates.

Planned features

  • Charge percentage, power source and charging state
  • Cycle count and capacity/health indicators as macOS reports them
  • Charging details and time estimates where available
  • Temperature only where macOS exposes it reliably
  • Never claims exact degradation when the OS gives an estimate

How it works

  1. Open BatteryPeek from the launcher.
  2. Read the live state and health indicators.
  3. Copy details if you need to share them.

Installation

BatteryPeek is not released yet. It is already listed in MacPeek's Manage utilities screen as Coming soon; when it ships it will appear there to switch on, with no separate download. Install MacPeek to get the launcher and PortPeek, DisplayPeek, USBPeek, NetPeek, SleepPeek, FileLockPeek, ProcessPeek, DiskPeek, EnvPeek and DNSPeek today.

Privacy

What will BatteryPeek do?
