DiskPeek: See which processes are hitting your disk.

Which app is using my disk right now?

DiskPeek is built and part of MacPeek's source. The first signed download has not been published yet; see Download for how to build it today.

The problem

The fans spin up and the disk light is on. Which app is reading and writing so much?

The solution

DiskPeek samples the disk read and write counters macOS keeps for each of your processes, every couple of seconds, and shows the busiest ones as rates and as totals since you opened it. Everything is labelled as sampled. Sampling stops the moment you leave the screen, and it starts from a fresh baseline each time.

Features

  • Per-process read and write rates over the last sampling interval
  • Totals since you opened DiskPeek, so brief bursts are not missed
  • Order by what is busy right now or by the total since opening
  • Clearly labelled as sampled values
  • Samples only while the screen is open; nothing runs in the background
  • Other users’ and protected processes are counted but not shown, and it says so
  • Not a disk-space cleaner

How it works

  1. Open DiskPeek from the launcher.
  2. Wait one sampling interval for the first rates.
  3. Leave the screen and sampling stops.

Installation

DiskPeek is part of MacPeek. Install MacPeek, open Manage utilities and make sure DiskPeek is switched on (it is on by default). There is nothing separate to download.

Privacy

What DiskPeek reads:

  • Per-process disk I/O counters (libproc) for processes your user can inspect, only while DiskPeek is open

Access it needs: None. Other users’ processes are not shown.

Everything stays on your Mac: no account, no telemetry, no network access. Read the full privacy statement.
