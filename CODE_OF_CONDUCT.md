# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent, keep feedback about the work rather than the person, and do not
harass, discriminate or publish others' private information. Maintainers may remove comments,
issues or contributions that violate these principles and may ban repeat offenders.
Report problems privately to the maintainers via a GitHub security advisory or by contacting the
repository owner on GitHub.
